## Implementation

A populated-field station-details panel replaces the raw-first enrichment presentation. Country/DXCC, operating versus callbook grid, distance/bearing and zones remain visible; contact/QSL, license/identity, operating location and address/coordinate groups scroll independently. Empty values/groups disappear, but explicit No/false and zero values are retained. Each field keeps its available provider attribution. Raw nonempty fields remain expandable, source retrieval times and cached/stale/error states remain visible, and a separate Refresh details action refreshes enrichment.

Worked-before and current-band status remain ahead of details. Complete QSO results additionally show available worked bands, modes and confirmation coverage. Contact dialogs scroll within the viewport, skip empty optional fields, retain actual contact provenance/reports/grids, and label time in UTC. Keyboard validation exposed an existing watcher bug: replacing SSE metadata with the same callsign/lookup ID closed the dialog and reset progressive contact rows. The watcher now compares the callsign and lookup ID individually, so ordinary Decode snapshots preserve the open dialog and row count. Header identity uses the provider's formatted name when available. QRZ biography is linked when advertised; remote biography HTML is not fetched/rendered. Inline biography content remains a later refinement, so this is an initial preview rather than a claim of complete Step 4 acceptance.

The backend, provider transports, credentials, configuration and database schema are unchanged. The map follow-up adds Leaflet as a locked frontend dependency. Radio and Wavelog processing retain their independent asynchronous/generation guards. No QSO writes, forwarding, commands or Step 5 work are included.
