# v0.9.0-beta.1 — draft pre-release notes

**Proposed version; not released, tagged or approved for publication.**

WSJT-X Dashboard brings station context and QSO history into a browser beside your operating session. Select a station in WSJT-X to see available operator details/photos, location, map and worked-before information. Revisit selected stations across multiple rigs without changing the radio.

## In this first beta

- Live station focus and shared, persistent Focus History.
- Compact callsign/current-band status with honest incomplete-history states and immediate local completion observations.
- Optional QRZ/pyhamtools enrichment and Wavelog API v2 history.
- Wavelog-optional ADIF history/logging; direct enriched Wavelog submission when configured.
- Automatic station-location matching and independent durable delivery/recovery for each destination.
- One-way original/enriched WSJT-X UDP forwarding.
- Operator documentation, field mappings and a read-only Wavelog export audit.
- Trusted HTTP host validation and owner-only configuration/private state permissions, with existing Origin protections retained.

## Install and upgrade

Use the [installation guide](../installation.md) and [quick start](../quick-start.md). Requires Git, Python 3.12–3.14 and internet access. The installer reuses compatible Node/npm or obtains a checksum-pinned temporary Node build toolchain for macOS/Ubuntu x64/ARM64. No published beta tag should be assumed until release approval. A source build is the documented delivery method; there are no verified Windows installers or Docker images.

For upgrades, stop Dashboard and privately back up configuration, all `data/` stores and every configured/queued ADIF file. Existing settings, history, outbox work and receipts are retained; do not recopy defaults. Configure one uploader per contact stream before enabling Wavelog delivery. Dashboard does not stop WaveLogGate or other uploaders for you.

## What has actually been verified

macOS arm64 operation includes multiple WSJT-X instances, QRZ/Wavelog reads and GridTracker2 reception. Automated coverage exercises selection ordering, asynchronous lookups, history completeness, enrichment, per-destination delivery, duplicates, reconciliation, forwarding and installed shutdown. The [readiness checklist](../release-readiness.md) records exact fresh test/install results and remaining gates.

## Beta limitations

Ubuntu is documented but has not been executed for acceptance. Windows, Docker and MacLoggerDX integration are unverified. Full isolated Wavelog write/outage validation and newly added optional-field live export acceptance remain pending. Wavelog 3.2.3 omits some accepted values from ADIF exports and normalizes others. GridTracker receiver testing found version-specific Unicode/fractional-power behavior. Inline biography retrieval is deferred.

The Dashboard has no login system; use loopback or a deliberately trusted network. Internet/WebGL are required for the basemap. Repeated same-call WSJT-X selections may not be observable. No exactly-once delivery guarantee is claimed across UDP and a remote API.
